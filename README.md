# What our program does

Our program finds the square root of a number with two methods, Newton and
bisection. Both start with a guess and make it better again and again, until the guess is close
enough. Each function gives back the answer and the number of steps it needed, so we can
see which method is faster.
Not knowing what the user will want to enter in the calculator, we used a function
convert to first convert what the user enters. So the user can give a number, but also a number
written as text, like &quot;3&quot; or &quot;-0.25&quot;. And if what is entered is not a number at all, the user gets
a message instead of an error.
